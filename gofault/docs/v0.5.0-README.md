# gofault v0.5.0

> 构造器注入完善 + Middleware 链 + Exception Filter + 生命周期钩子

## 版本概述

v0.5.0 是 gofault 框架的第二个正式版本，在 v0.1.0 最小内核基础上增加了中间件链、异常过滤和生命周期钩子三大特性。

## 核心特性

### 1. Middleware 中间件链

中间件函数签名：

```go
type MiddlewareFunc func(ctx *core.Ctx, next Handler) error
type Handler func(ctx *core.Ctx) error
```

- 全局中间件：注册到 `core.Module.Middleware`，自动应用到该模块所有路由
- 路由级中间件：通过 `Route` 结构体的 `Middleware` 字段单独指定
- 执行顺序：注册顺序（FIFO），最后一个中间件调用实际 handler

```go
// 定义中间件
func loggingMiddleware(ctx *core.Ctx, next core.Handler) error {
    fmt.Println("before:", ctx.Request.URL.Path)
    err := next(ctx)
    fmt.Println("after:", ctx.Request.URL.Path)
    return err
}

// 注册到模块
mod := core.NewModule()
mod.RegisterMiddleware(loggingMiddleware)
```

### 2. Exception Filter 异常过滤

异常过滤器接口：

```go
type ExceptionFilter interface {
    Capture(ctx any, err error) bool
}
```

内置 HTTP 异常工厂函数：

```go
exception.BadRequest("invalid input")
exception.Unauthorized("not authenticated")
exception.Forbidden("access denied")
exception.NotFound("resource not found")
exception.InternalServerError("something went wrong")
exception.Conflict("resource conflict")
```

内置实现 `HTTPExceptionFilter` 将异常转换为标准 JSON 响应：

```json
{"code": 400, "message": "invalid input"}
```

注册方式：

```go
router := router.New()
router.ExceptionFilter(exception.NewHTTPExceptionFilter())
```

### 3. 生命周期钩子

```go
type OnBoot interface {
    OnBoot() error
}

type OnShutdown interface {
    OnShutdown() error
}
```

- `OnBoot`：应用启动时调用（在 server.Start() 之前）
- `OnShutdown`：应用关闭时调用（逆向顺序）

```go
type MyHook struct{}

func (h *MyHook) OnBoot() error {
    fmt.Println("应用启动")
    return nil
}

func (h *MyHook) OnShutdown() error {
    fmt.Println("应用关闭")
    return nil
}

mod.RegisterOnBoot(&MyHook{})
mod.RegisterOnShutdown(&MyHook{})
```

### 4. Handler 反射分发

Handler 方法通过反射调用，避免了经典 Go 闭包捕获 bug：

```go
type Route struct {
    Method  string
    Path    string
    Handler string // 方法名，如 "Greet", "Index"
}
```

`makeHandler` 辅助函数将 `route` 值传递进闭包，而非引用捕获：

```go
func makeHandler(ctrl core.Controller, route core.Route) core.Handler {
    return func(ctx *core.Ctx) error {
        return controller.InvokeHandler(ctrl, route.Method, route.Path, route.Handler, ctx)
    }
}
```

### 5. 构造器注入完善

Provider 通过 IoC 容器自动实例化：

```go
type UserService struct{}

func (s *UserService) Provide() any {
    return &UserService{}
}

mod.RegisterProviders(&UserService{})
```

## 目录结构

```
gofault/
├── core/           # 核心接口定义（Ctx, Route, Module, Controller, Provider, MiddlewareFunc）
├── ioc/            # IoC 容器（构造器注入、依赖解析）
├── controller/     # Controller 基类（JSON/Text 响应、Path/Query 参数提取）
├── router/         # HTTP 路由器（中间件链、异常过滤）
├── module/         # App 引导（Bootstrap/Start/Stop、生命周期钩子）
├── exception/      # HTTP 异常类型 + ExceptionFilter
├── provider/       # Provider 工具函数
├── server/         # HTTP Server 封装
├── docs/           # 文档
└── examples/hello/ # 示例应用
```
