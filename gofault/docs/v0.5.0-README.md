# gofault v0.5.0

> 构造器注入完善 + Middleware 链 + Exception Filter + 生命周期钩子

## 版本概述

v0.5.0 是 gofault 框架的第二个正式版本，在 v0.1.0 最小内核基础上增加了中间件链、异常过滤和生命周期钩子三大特性。

## 核心特性

### 1. Middleware 中间件链

中间件函数签名：

```go
type MiddlewareFunc func(ctx *core.Ctx, next Handler) error
type Handler func(ctx *core.Ctx) error
```

- 全局中间件：注册到 `core.Module.Middleware`，自动应用到该模块所有路由
- 路由级中间件：通过 `Route` 结构体的 `Middleware` 字段单独指定
- 执行顺序：注册顺序（FIFO），最后一个中间件调用实际 handler

```go
// 定义中间件
func loggingMiddleware(ctx *core.Ctx, next core.Handler) error {
    fmt.Println("before:", ctx.Request.URL.Path)
    err := next(ctx)
    fmt.Println("after:", ctx.Request.URL.Path)
    return err
}

// 注册到模块
mod := core.NewModule()
mod.RegisterMiddleware(loggingMiddleware)
```
